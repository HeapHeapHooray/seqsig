# SeqSig (Sequential Signature)

> **Designed & Implemented with Antigravity AI (Gemini 3.6 Flash)** — Google DeepMind

**SeqSig** is a ledgerless, cryptographically verifiable 512-bit Secret Seed Sequential Identity and Signature CLI powered by SHAKE-256 PRNG key-ratcheting.

Install **SeqSig** directly using [`uv`](https://github.com/astral-sh/uv):

## 🔒 Core Concept & Security Model

The holder of a 512-bit Master Secret Seed can deterministically compute nonces in **~5 microseconds**, whereas external observers face a $2^{512}$ brute-force search space ($\approx 10^{138}$ universe lifetimes) to forge a valid block.

### Key Innovations

1. **100% Ledgerless Verification**: No global ledger, database, or network consensus needed. Blocks verify each other sequentially.
2. **Private PRNG Numbers ($N_k$)**: Raw PRNG numbers ($N_k$) generated by the secret seed are **NEVER published**.
3. **Implicit Hash Commitment & Delayed Revelation**:
   - **Block $k$ Commitment**: $\text{block\_hash}_k = \text{SHA-512}(\text{data}_k + \text{SHA-512}(N_k))$
   - **Block $k+1$ Revelation**: Block $k+1$ reveals $\text{SHA-512}(N_k)$ as **`previous_nonce`**, unlocking and verifying Block $k$'s `block_hash`.
4. **Verification Formula**: $\text{SHA-512}(\text{data}_k + \text{previous\_nonce}_{k+1}) = \text{block\_hash}_k$
5. **Final Settlement Block**: Discloses the **master seed** and **PRNG algorithm** (`CryptoPRNG512` SHAKE-256), enabling anyone to perform a **100% retrospective audit** of the entire chain from Genesis #0 to Final #N.

## 🚀 Quick Start & CLI Usage

### 1. Generate 512-Bit Secret Seed & Public Identity
```bash
seqsig gen-seed -o seed.key
```

### 2. Create Genesis Block #0
```bash
seqsig genesis -s seed.key -d "Genesis identity block" -o b0.json
```

### 3. Mint Next Block (Block #1) by Feeding Current Block (Block #0)
```bash
seqsig mint b0.json -s seed.key -d "Transaction #1 data" -o b1.json
```

Mint Block #2 by feeding Block #1 (`b1.json`):
```bash
seqsig mint b1.json -s seed.key -d "Transaction #2 data" -o b2.json
```

### 4. Verify Chain Integrity & Pre-Image Revelation
```bash
seqsig verify b1.json -p b0.json
```

**Output:**
```text
================================================================================
VERIFYING BLOCK #1
================================================================================
  Data                 : 'Transaction #1 data'
  Previous Nonce       : e16e1288e65cb98f5962e33425ac7ff0...
  Block Hash           : 8e7810df2ed47dcddf17683e1a6313d2...

VERIFYING BLOCK #0 VIA REVEALED NONCE IN BLOCK #1:
  H(Data + Nonce) = BLOCK_HASH
  H('Genesis identity block' + e16e1288e65cb98f...) = 3e7034e561bd3ed41c7fd56b275eef2a...

✅ RESULT: H(Data + Nonce) = BLOCK_HASH (VALID)
```

### 5. Close Chain with Final Settlement Block
```bash
seqsig final b2.json -s seed.key -d "Final Settlement - Disclose Seed" -o b3_final.json
```

Verify final block with retrospective seed audit:
```bash
seqsig verify b3_final.json -p b2.json
```
